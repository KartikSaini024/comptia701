# Security+ SY0-701 Map

An interactive mind map of the CompTIA Security+ SY0-701 syllabus: 5 domains, 28 objectives,
656 topic cards with explanations and exam tips, recall mode, flashcards and a 300+ acronym glossary.

It is a single self-contained `index.html` (no build step, no Node, no dependencies).
Progress (cards marked as known) is saved in your browser's localStorage.

## Run locally
Double-click `index.html`, or serve the folder: `npx serve .`

## Host on Vercel
1. Create a new GitHub repository and upload `index.html` and this README.
2. In Vercel, choose **Add New → Project**, import the repository.
3. Framework preset: **Other**. Leave build command and output directory empty.
4. Deploy. Vercel serves `index.html` at the root URL.

(GitHub Pages works too: Settings → Pages → Deploy from branch → `main` / root.)

## Keyboard shortcuts
Arrows move through the tree, Enter opens/closes, N/P next/previous topic, K mark known,
1–5 jump to a domain, / search, R recall mode, S flashcards, G acronyms, F fit, T theme, ? help.
